# Style guide

## Brand

**Pawfect Home** is warm, calm, and trustworthy. The paw + wordmark logo is intentionally text-based so it stays sharp and accessible at any size. Voice: hopeful, direct, never sentimental at the animal's expense.

## Colour

| Token | Hex | Use |
| --- | --- | --- |
| Forest | `#345B4C` | Primary actions, footer |
| Coral | `#E98064` | Secondary accent, eyebrows |
| Cream | `#FAF7F0` | Page background |
| Sage | `#DBE7D9` | Soft supporting surfaces |
| Ink | `#24352F` | Primary text |
| Muted | `#65736E` | Secondary text |
| White | `#FFFFFF` | Cards and contrast surfaces |

Forest on white and Ink on Cream are the primary accessible text combinations. Coral is decorative or used for large/bold text, not body copy.

## Typography

- Display: **Fraunces**, 600–700, for warm editorial headings.
- Interface/body: **DM Sans**, 400–700, for clarity at small sizes.
- Fallbacks are system serif and sans-serif fonts.

## Components

- Buttons: pill shape, 44px+ target, Forest primary and pale neutral secondary.
- Cards: 18px radius, hairline border, image-first, modest lift on hover.
- Status chips: green Available, amber Pending, grey Adopted; always include text.
- Fields: persistent labels, 12px radius, native validation, clear error copy.
- Layout: 1200px maximum width, 8px spacing rhythm, breakpoints at 850px and 560px.

## Image direction

Use natural-light, eye-level animal portraits with uncluttered backgrounds. Crop with `object-fit: cover`, retain descriptive alt text, and avoid images that portray distress.
